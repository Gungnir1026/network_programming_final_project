# TCP 通訊協定

傳輸採 **UTF-8 文字，每個訊息一行，以換行結束**。整理版加入登入確認與結構化聊天，老師、學生及伺服器應使用同一份整理版 JAR；不與 `ip/` 的舊執行檔混用。

## 登入

1. 伺服器送出 `NICK`。
2. 客戶端送出 `姓名 (老師)` 或 `姓名 (學生)`。
3. 成功回覆 `JOINED|完整暱稱`；失敗回覆 `ERROR|原因` 並關閉連線。

姓名為 1–40 個 Java 字元，不可為空白或含 `,`、`;`、`:`、`|`、換行；同角色不得重名，一間教室限一位老師。客戶端連線／交握、伺服器等待暱稱的逾時均為 5 秒。完成交握才會加入在線名單。

## 課堂互動

| 方向 | 訊息 | 說明 |
| --- | --- | --- |
| 任意端 → Server | `CHAT|內容` | Server 加上發送者暱稱後，送給全部成員 |
| Server → 全部 | `暱稱: 內容` | 聊天顯示文字，包含發送者 |
| Server → 其他成員 | `SYSTEM|文字` | 成員加入／離線通知 |
| 客戶端 → Server | `GET_USERS` | 請求目前學生名單 |
| Server → 請求者 | `USER_LIST:2,小明 (學生),小美 (學生),` | 人數、完整學生暱稱，保留末尾逗號 |
| 學生 → Server → 老師 | `RAISE_HAND` → `HAND_RAISED:完整暱稱` | 舉手通知 |
| 老師 → Server → 學生 | `ANNOUNCE:內容` | 通知所有學生，老師自行顯示發送確認 |
| 老師 → Server | `ALLOW_DRAW_TO:完整學生暱稱` | 指定學生回覆 `ALLOW_DRAW` |
| 老師 → Server | `DISALLOW_DRAW_TO:完整學生暱稱` | 指定學生回覆 `DISABLE_DRAW` |
| 老師 → Server → 全部 | `SYSTEM|抽籤結果公布：名單` | 抽籤由老師端產生並廣播 |
| Server → 操作者 | `ERROR|原因` | 指令、角色、授權或目標錯誤 |

## 白板

老師與已授權學生可以送出。伺服器轉送給其他成員，**不回送發送者**。

```text
DRAW_BEGIN x y r g b size
DRAW_MOVE x1 y1 x2 y2 r g b size
DRAW_END
ERASE_BEGIN size
ERASE_MOVE x y
ERASE_END
UNDO
REDO
CLEAR
```

座標為整數，絕對值不超過 10000；RGB 各為 0–255；粗細為 1–100。白板使用視窗內的像素座標，尚未做不同大小視窗間的比例換算。示範時讓所有客戶端使用相同視窗尺寸，並從開始到結束完整傳送每一筆操作。

## 測驗

| 訊息 | 方向與用途 |
| --- | --- |
| `QUIZ_DATA:題數;;題幹|選項A|選項B;;…;;` | 老師 → 學生；傳送題庫，不包含正解 |
| `QUIZ_GOTO:題號` | 老師 → 學生；題號從 1 起算 |
| `SUBMIT_ANS:題號:選項索引` | 學生 → Server；選項從 0 起算 |
| `SUBMIT_ANS:學生暱稱:題號:選項索引` | Server → 老師；附加發送者身分後交給老師計分 |
| `QUIZ_RESULT:名次,暱稱,分數;…;` | 老師 → 學生；依分數遞減、同分依暱稱排序 |
| `QUIZ_RESULT:NO_DATA` | 無學生提交有效答案 |
| `QUIZ_END` | 關閉測驗；老師離線時 Server 也會送出 |

伺服器只轉送測驗進行中、當前題目的首次提交；老師端再次檢查題號、選項範圍與重複答案。答錯記 0 分，結束後不再接受答案。內建題庫總分 100 分。

此協定尚未提供分隔字元跳脫。自訂題幹／選項時避免換行、`|` 與 `;;`；若要支援自由文字題庫，可將通訊格式改為具備跳脫規則的 JSON 訊息。
