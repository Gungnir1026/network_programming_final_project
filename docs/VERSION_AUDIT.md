**以 `ip/eclassroom_0o0` 作為 GitHub 展示版的整理基底。** 它的 14 份 Java 原始碼共 3385 行，最後修改時間是 **2025-12-15 23:27:21（Asia/Taipei）**；是 13 個版本中修改時間最晚的版本，也完整包含共享白板、聊天、舉手、公告、在線學生與授權、抽籤、測驗及排行榜。
